# Brag plan: GitHub + Claude Code, in Plain English (Cohort 3)

**Source:** `index.html` in this repo (the Cohort 3 landing page), rendered in a headless browser.
**Format:** vertical 1080×1920, 30fps, 22.2s. **Tone:** `polished`, with the direction "calm and reassuring, the opposite of scary tech".

## The questions

- **What is it?** A live, three-session course that teaches non-technical AI-preneurs to use GitHub by asking Claude Code in plain English.
- **Who is it for?** AI-preneurs, professionals, business owners and creators building with Claude, ChatGPT, Claude Code or Codex who find GitHub scary.
- **What sets it apart?** No commands to memorise. You learn the ideas (commit, branch, going back) and Claude does the typing.
- **Most impressive claim:** "Claude Code does the typing for you."
- **Visual hook:** the page's own jargon chips (`branches` `commits` `pushes` `pulls` `merges` `a terminal`) crowding the screen, then the orange "in Plain English" highlight.
- **Real UI to show:** the plain-English request bubbles from the navy "Claude Code does the typing for you" section.
- **Share caption:** see `share-copy.txt`.

## Angle

Scary to calm. Open on the jargon that puts people off, then answer it with the course name and the actual plain-English requests. Close on proof (a student quote) and the teacher (Vik's face). Every line of copy comes from the page.
